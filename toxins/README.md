# Toxins by category

A toxin has no ATC code, so the site groups toxins by their T3DB category — one primary category per toxin, the most specific it carries (a pesticide that is also an industrial chemical is listed as a pesticide) — and, on each category page, by chemical class (ClassyFire, from T3DB's taxonomy). Only toxins with pipeline results are listed.
