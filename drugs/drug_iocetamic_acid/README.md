## About

Iocetamic acid is an iodinated, water-soluble X-ray contrast agent that is taken up by the liver and used to visualise the gallbladder and biliary tract on imaging. It is an approved contrast medium, though such oral gallbladder agents are now only rarely used, having largely been replaced by modern imaging techniques.
