# isatuximab

- **ATC codes:** `L01FC02`, `L01XC38`

## About

Isatuximab is a monoclonal antibody that targets CD38 for the treatment of multiple myeloma. The medication is usually administered by intravenous injection, while subcutaneous injection is also an available route. It is used for multiple myeloma and is authorised in the European Union.
