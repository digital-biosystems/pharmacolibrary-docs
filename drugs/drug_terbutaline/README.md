# terbutaline

- **generic name:** terbutaline
- **ATC codes:** `R03AC03`, `R03CC03`
- **DrugBank:** [DB00871](https://go.drugbank.com/drugs/DB00871) · **PubChem:** [CID 5403](https://pubchem.ncbi.nlm.nih.gov/compound/5403)

- **groups:** approved, investigational

## About

Terbutaline is a beta-2 agonist bronchodilator used to treat asthma and other obstructive lung diseases. It is an approved medicine, available as inhalation and systemic formulations, and has also been investigated as a uterine relaxant.
