# Lyngbyatoxin A

- **generic name:** Lyngbyatoxin A
- **T3DB:** [T3D4088](http://www.t3db.ca/toxins/T3D4088) · **PubChem:** [CID 3979](https://pubchem.ncbi.nlm.nih.gov/compound/3979)

## About

Lyngbyatoxin A is a cyanotoxin produced by certain cyanobacteria species, notably <i>Moorea producens</i> (formerly classified as <i>Lyngbya majuscula</i>). It is used as a defensive secretion to protect this cyanobacteria from predation by fish, being a potent irritant and vesicant, as well as a carcinogen. Low concentrations more commonly encountered cause milder symptoms, known as seaweed dermatitis. …
