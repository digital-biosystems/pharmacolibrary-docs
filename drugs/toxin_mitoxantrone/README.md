# Mitoxantrone

- **generic name:** Mitoxantrone
- **T3DB:** [T3D3020](http://www.t3db.ca/toxins/T3D3020) · **DrugBank:** [DB01204](https://go.drugbank.com/drugs/DB01204) · **PubChem:** [CID 4212](https://pubchem.ncbi.nlm.nih.gov/compound/4212)
- **groups:** approved, investigational

## About

Mitoxantrone is only found in individuals that have used or taken this drug. It is an anthracenedione-derived antineoplastic agent. Mitoxantrone, a DNA-reactive agent that intercalates into deoxyribonucleic acid (DNA) through hydrogen bonding, causes crosslinks and strand breaks. …

- **Category:** Drug, Synthetic Toxin
- **Route of exposure:** intravenous injection. Poorly absorbed following oral administration.
- **Sources and uses:** For the treatment of secondary (chronic) progressive, progressive relapsing, or worsening relapsing-remitting multiple sclerosis. Mitoxantrone is an Anthracenedione (not an anthracycline) antineoplastic agent.
- **Mechanism of toxicity:** Mitoxantrone, a DNA-reactive agent that intercalates into deoxyribonucleic acid (DNA) through hydrogen bonding, causes crosslinks and strand breaks. Mitoxantrone also interferes with ribonucleic acid (RNA) and is a potent inhibitor of topoisomerase II, an enzyme responsible for uncoiling and repairing damaged DNA. …
- **Health effects:** Cardiomyopathy is a particularly concerning effect as it is irreversible. [Wikipedia]
- **Carcinogenicity:** IARC group 2B, possibly carcinogenic to humans.
