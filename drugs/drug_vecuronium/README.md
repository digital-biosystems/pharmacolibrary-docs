# vecuronium

- **generic name:** vecuronium
- **ATC codes:** `M03AC03`

- **groups:** approved, investigational

## About

Vecuronium is a muscle relaxant used to relax muscles during surgery and mechanical ventilation. It is given by injection and is restricted to hospital use, mainly in anaesthesia and intensive care.
