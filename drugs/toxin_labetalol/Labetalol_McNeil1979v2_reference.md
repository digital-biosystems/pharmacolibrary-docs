**The clearance parameter is mislabeled 'Endogenous CL', causing rejection as biomarker kinetics rather than labetalol PK, with abstract-only data limiting model fidelity.**

A retention function with one pool was applied, using the 3.25-hour half-life to define the terminal decline. Extracted — labetalol: t1/2z 3.25 hours, CL 8 mL/min, V 4 L/kg, kabs 19.8 h−1.
