# Rocuronium

- **generic name:** Rocuronium
- **ATC codes:** `M03AC09`
- **DrugBank:** [DB00728](https://go.drugbank.com/drugs/DB00728) · **PubChem:** none
- **groups:** approved, investigational

## About

Rocuronium is a non-depolarising neuromuscular blocking agent used to relax muscles, for example during surgery. It is an approved medicine and is widely used in anaesthesia, mainly in hospital settings.
