## About

Amantadine is a dopaminergic agent used to treat Parkinson's disease, associated dyskinesia, and influenza. It is given by mouth in forms such as tablets, capsules, and solutions. While its use for influenza is no longer recommended due to resistance, it remains in use for neurological conditions.
