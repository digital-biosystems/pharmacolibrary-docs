## About

Pentamidine is an antimicrobial agent used to treat leishmaniasis, trypanosomiasis, and pneumocystis pneumonia. It is administered via intravenous or intramuscular injection, while inhalation is used for lung conditions. The drug is widely used and listed on the World Health Organization's essential medicines list.
