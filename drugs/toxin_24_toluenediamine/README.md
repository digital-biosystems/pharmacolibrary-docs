# 2,4-Toluenediamine

- **generic name:** 2,4-Toluenediamine
- **T3DB:** [T3D4669](http://www.t3db.ca/toxins/T3D4669) · **PubChem:** [CID 7261](https://pubchem.ncbi.nlm.nih.gov/compound/7261)

## About

2,4-Diaminotoluene is an aromatic organic compound with the formula C6H3(NH2)2CH3. It is one isomer of six with this formula. It is a white solid, although commercial samples are often yellow-tan.

<p><small>Source: <a href="https://en.wikipedia.org/wiki/2%2C4-Diaminotoluene?oldid=1367975860">Wikipedia</a> · <a href="https://creativecommons.org/licenses/by-sa/4.0/">CC BY-SA 4.0</a></small></p>

- **Category:** Industrial/Workplace Toxin, Pollutant, Airborne Pollutant, Synthetic Toxin
- **Carcinogenicity:** IARC group 2B, possibly carcinogenic to humans.
