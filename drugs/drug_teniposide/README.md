## About

Teniposide is a podophyllotoxin derivative and topoisomerase II inhibitor used to treat childhood acute lymphocytic leukemia, Hodgkin's lymphoma, certain brain tumours, and lung oat cell carcinoma. It is given by intravenous injection. It is an approved chemotherapeutic medication used for cancer treatment.
