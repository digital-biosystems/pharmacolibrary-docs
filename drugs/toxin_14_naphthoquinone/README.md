# 1,4-Naphthoquinone

- **generic name:** 1,4-Naphthoquinone
- **T3DB:** [T3D4637](http://www.t3db.ca/toxins/T3D4637) · **PubChem:** [CID 8530](https://pubchem.ncbi.nlm.nih.gov/compound/8530)

## About

1,4-Naphthoquinone or para-naphthoquinone is an organic compound derived from naphthalene. Several isomeric naphthoquinones are known, notably 1,2-naphthoquinone. 1,4-Naphthoquinone forms volatile yellow triclinic crystals and has a sharp odor similar to benzoquinone. It is almost insoluble in cold water, slightly soluble in petroleum ether, and more soluble in polar organic solvents. …

- **Category:** Cigarette Toxin, Industrial/Workplace Toxin, Pollutant, Food Toxin, Synthetic Toxin
- **Sources and uses:** This is a toxic chemical found in cigarettes or generated by tobacco combustion.
