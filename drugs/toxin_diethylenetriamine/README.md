# Diethylenetriamine

## About

Constituent of ion-exchange resins for use in food processing, e.g. in the production of grapefruit juice Diethylenetriamine (DETA) is a colourless hygroscopic liquid, soluble in water and hydrocarbons. Diethylenetriamine is an analogue of diethylene glycol. It has similar chemical behavior as ethylene diamine and has similar uses. …
