### Reviewer guidance

**Methotrexate bioavailability and lag time were assigned library defaults because only abstract data was available, failing the model acceptance criteria.**

The bioavailability and absorption lag time for methotrexate were substituted with default values rather than extracted estimates. This occurred because the model was derived exclusively from the paper's abstract, meaning reported summary statistics were used as stand-ins for a fitted model. Consequently, these unsupported parameter values affect the simulated concentration profile. Extracted — methotrexate: CL 5.75 L/h, V1 21.3 L, V2 8.2 L, Q 0.087 L/h, kabs 0 1/min.
