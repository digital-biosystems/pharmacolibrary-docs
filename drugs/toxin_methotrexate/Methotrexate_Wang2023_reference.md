### Reviewer guidance

**The intercompartmental return rate constant k21 for methotrexate was defaulted rather than estimated from the reported two-compartment model parameters.**

The record extracts methotrexate clearance, central volume, and intercompartmental clearance, but the peripheral return rate constant (k21) was left at library defaults instead of being derived or reported. This unreported parameter affects the simulated concentration-time profile for the two-compartment structure. Consequently, the model was held for review because simulated outputs rely on unsupported default values for k21. Extracted — methotrexate: CL 3.52 L/h, V1 7.5 L, Q 0.41 L/h.
