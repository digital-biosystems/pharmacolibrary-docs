# roflumilast

- **generic name:** roflumilast
- **ATC codes:** `D05AX06`, `R03DX07`
- **DrugBank:** [DB01656](https://go.drugbank.com/drugs/DB01656) · **PubChem:** [CID 449193](https://pubchem.ncbi.nlm.nih.gov/compound/449193)

## About

It is given orally as tablets or topically as creams or foams. Roflumilast is authorised in the European Union and is also available as a generic medication.
