## About

Mezlocillin is an extended-spectrum penicillin antibiotic used to treat bacterial infections such as sepsis, urinary tract, skin, and respiratory infections, including Pseudomonas and other gram-negative infections. It is an approved antibacterial, though it is not authorised in the European Union and is now used only in a limited number of countries.
