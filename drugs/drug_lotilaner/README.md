## About

Lotilaner is an antiparasitic drug sold as Credelio, used mainly to treat flea and tick infestations in dogs and cats, and is also being studied as an eye treatment for parasitic eyelid disease. It is an approved veterinary medicine, and an ophthalmic use is still investigational.
