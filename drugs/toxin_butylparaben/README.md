## About

Butylparaben is a preservative and flavouring agent. Butylparaben has been shown to exhibit anti-microbial function Butylparaben belongs to the family of Hydroxybenzoic Acid Derivatives. These are compounds containing an hydroxybenzoic acid (or a derivative), which is a benzene ring bearing a carboxylic acid..
