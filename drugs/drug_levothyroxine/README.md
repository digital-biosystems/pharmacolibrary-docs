# Levothyroxine

- **generic name:** Levothyroxine
- **ATC codes:** `H03AA01`, `H03AA51`

- **groups:** approved, investigational

## About

Levothyroxine is a synthetic thyroid hormone prescribed for hypothyroidism, goiter, and specific thyroid cancers. It is primarily taken orally as a tablet, though intravenous injection is used when oral intake is not possible. The medication is widely available as a generic option and appears on the World Health Organization list of essential medicines.
