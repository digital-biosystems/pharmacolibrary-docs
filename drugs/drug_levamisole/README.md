# levamisole

- **generic name:** levamisole
- **ATC codes:** `P02CE01`
- **DrugBank:** [DB00848](https://go.drugbank.com/drugs/DB00848) · **PubChem:** [CID 26879](https://pubchem.ncbi.nlm.nih.gov/compound/26879)
- **molar mass:** 204.291 g/mol (C11H12N2S) — DrugBank
- **groups:** approved, investigational, vet_approved, withdrawn

## About

Levamisole is an antinematodal drug used to treat worm infections and has also been used for benign colonic tumours. It is a WHO essential medicine and is also approved for veterinary use, though some uses have been withdrawn.
