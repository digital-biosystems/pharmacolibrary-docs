# Cetyl-Trimethyl-Ammonium

- **generic name:** Cetyl-Trimethyl-Ammonium
- **T3DB:** [T3D4814](http://www.t3db.ca/toxins/T3D4814) · **DrugBank:** [DB01718](https://go.drugbank.com/drugs/DB01718) · **PubChem:** [CID 2681](https://pubchem.ncbi.nlm.nih.gov/compound/2681)
- **groups:** approved, investigational

## About

Cetyl-Trimethyl-Ammonium, Cetrimonium, cetyl trimethylammonium, or hexadecyltrimethylammonium is a quaternary ammonium cation whose bromide and chloride salts are used as antiseptics.

- **Category:** Household Toxin, Industrial/Workplace Toxin, Synthetic Toxin
- **Sources and uses:** Cetyl-Trimethyl-Ammonium, Cetrimonium, cetyl trimethylammonium, or hexadecyltrimethylammonium is a quaternary ammonium cation whose bromide and chloride salts are used as antiseptics.
