## About

Diphenhydramine is a first-generation antihistamine with sedative properties, primarily used to treat allergies, insomnia, and urticaria. It is usually taken orally, but it can also be applied to the skin or administered via intravenous injection. It is a widely available generic medication used commonly for these indications.
