# N'-nitrosonornicotine

- **generic name:** N'-nitrosonornicotine
- **T3DB:** [T3D4215](http://www.t3db.ca/toxins/T3D4215) · **PubChem:** [CID 27919](https://pubchem.ncbi.nlm.nih.gov/compound/27919)

## About

N'-nitrosonornicotine belongs to the family of Pyrrolidinylpyridines. These are compounds containing a pyrrolidinylpyridine ring system, which consists of a pyrrolidine ring linked to a pyridine ring.

- **Category:** Cigarette Toxin, Synthetic Toxin
- **Sources and uses:** This is a toxic chemical found in cigarettes or generated by tobacco combustion.
- **Carcinogenicity:** IARC group 1, carcinogenic to humans.
