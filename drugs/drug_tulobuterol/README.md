## About

Tulobuterol is a selective beta-2 adrenergic agonist that acts as a bronchodilator, intended for obstructive airway diseases such as asthma. It is considered investigational and is not authorised in the European Union; it has mainly been used in Japan, available as an inhaled or oral medication.
