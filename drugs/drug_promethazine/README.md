## About

Promethazine is an antihistamine of the phenothiazine class used to treat allergic conditions, itching, motion sickness, vomiting, and pain, and to manage postoperative complications. It is an approved medicine, available for systemic use as an antihistamine and also in topical antipruritic preparations, and is used fairly widely.
