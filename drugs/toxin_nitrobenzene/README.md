# Nitrobenzene

- **generic name:** Nitrobenzene
- **T3DB:** [T3D4216](http://www.t3db.ca/toxins/T3D4216) · **PubChem:** [CID 7416](https://pubchem.ncbi.nlm.nih.gov/compound/7416)

## About

Approximately 95% of nitrobenzene is consumed in the production of aniline, which is a precursor to rubber chemicals, pesticides, dyes, explosives, and pharmaceuticals. Nitrobenzene is an organic compound with the chemical formula C6H5NO2. It is a water-insoluble pale yellow oil with an almond-like odor. …

- **Category:** Cigarette Toxin, Pesticide, Industrial/Workplace Toxin, Pollutant, Airborne Pollutant, Synthetic Toxin
- **Carcinogenicity:** IARC group 2B, possibly carcinogenic to humans.
