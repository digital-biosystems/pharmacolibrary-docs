## About

Azathioprine is an immunosuppressive medication used to treat autoimmune diseases and prevent organ transplant rejection. It is usually taken orally in tablet form, as it is well absorbed, or given intravenously. It is a widely used essential medicine, authorised in the European Union for graft rejection.
