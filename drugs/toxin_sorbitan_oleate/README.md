# Sorbitan oleate

- **generic name:** Sorbitan oleate
- **T3DB:** [T3D4854](http://www.t3db.ca/toxins/T3D4854) · **PubChem:** [CID 5385498](https://pubchem.ncbi.nlm.nih.gov/compound/5385498)
- **groups:** experimental

## About

Sorbitan oleate is an emulsifier and clarification agent in food preparations (sugar liquor or juice) Sorbitan oleate belongs to the family of Pentoses. These are monosaccharides in which the carbohydrate moiety contains five carbon atoms.

- **Category:** Household Toxin, Food Toxin, Synthetic Toxin
