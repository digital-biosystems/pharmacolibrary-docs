# N-Butyl-Benzenesulfonamide

## About

N-Butyl benzenesulfonamide (NBBS), a plasticizer used commercially in the polymerization of polyamide compounds. It is neurotoxic and has been found to induce spastic myelopathy in rabbits.

- **Category:** Industrial/Workplace Toxin, Synthetic Toxin
- **Sources and uses:** N-Butyl benzenesulfonamide (NBBS), a plasticizer used commercially in the polymerization of polyamide compounds. It is neurotoxic and has been found to induce spastic myelopathy in rabbits.
