## About

Tetracosactide (cosyntropin) is a synthetic fragment of the pituitary hormone ACTH used to test how well the adrenal glands work, helping diagnose adrenal insufficiency. It is an approved medicine, used mainly in diagnostic testing, typically in hospital or specialist settings.
