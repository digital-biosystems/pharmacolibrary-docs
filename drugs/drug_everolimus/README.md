## About

Everolimus is an mTOR inhibitor used as an antineoplastic and immunosuppressant for cancers such as renal cell carcinoma, breast cancer, and neuroendocrine tumors, as well as tuberous sclerosis. It is authorised in the European Union for several cancer types and tuberous sclerosis, and is an approved drug.
