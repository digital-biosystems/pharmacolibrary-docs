# everolimus

- **generic name:** everolimus
- **ATC codes:** `L01EG02`, `L01XE10`, `L04AH02`

- **groups:** approved, investigational

## About

Everolimus is an immunosuppressant and mTOR inhibitor used to treat various cancers and prevent organ transplant rejection. The medication is administered orally in tablet forms. Routine blood level monitoring is performed to guide dosing. It is widely used and authorized in the European Union.
