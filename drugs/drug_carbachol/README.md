# carbachol

- **generic name:** carbachol
- **ATC codes:** `N07AB01`, `S01EB02`

- **groups:** approved

## About

Carbachol is a cholinergic agonist that primarily treats glaucoma and supports ophthalmic surgery. It is generally given as ophthalmic solution or eye drops. Although it can be taken orally or injected, it is poorly absorbed by mouth. The drug is listed as an essential medicine.
