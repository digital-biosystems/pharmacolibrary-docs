## About

Secretin is a hormone used as a diagnostic agent in tests of pancreatic function and in evaluating conditions such as exocrine pancreatic insufficiency and gastrinoma. It is an approved diagnostic agent, used mainly in specialised testing rather than as a routine treatment.
