# secretin

- **generic name:** secretin

## About

Secretin is a hormone used as a diagnostic agent to test pancreatic function, treating conditions such as exocrine pancreatic insufficiency and gastrinoma. It is given by intravenous injection. It is authorised for use in the European Union.
