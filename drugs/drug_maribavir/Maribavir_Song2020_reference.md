### Reviewer guidance

**The maribavir record was held back because the absorption rate constant ka (and lag time) was never reported in Song_2020, so library defaults would stand in for an unestimated absorption parameter.**

The record reports only CL/F = 2.19 L/h and V/F = 12.638 L (derived from CL·t½/ln2) for maribavir; the first-order absorption rate ka is not in the source, and the model builder substituted defaults for ka and Tlag. The apparent parameterization additionally assumes F=1 and Fm=1 with no molar correction, so the /F-adjusted values rest on an unreported bioavailability. The deviations check could not accept the defaulted parameters or the invented absorption, and the established note states the default ka values affect the simulated profile but are not supported by this paper. Extracted — maribavir: CL/F 2.19 L/h, V/F 12.6 L.

A second, independent reading of the paper (`gpt-oss-120b`) disagrees on parameter Q18: this record has none, the second reading 91.5; it also differs on 5 more fields. That field does not shape the model.
