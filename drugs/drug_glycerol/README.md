# glycerol

- **generic name:** glycerol
- **ATC codes:** `A06AG04`, `A06AX01`
- **DrugBank:** [DB09462](https://go.drugbank.com/drugs/DB09462)
- **groups:** approved, investigational

## About

**Description.** A trihydroxy sugar alcohol that is an intermediate in carbohydrate and lipid metabolism.

**Indication.** It is used as a solvent, emollient, pharmaceutical agent, and sweetening agent.
