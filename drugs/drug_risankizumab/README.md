# risankizumab

- **generic name:** risankizumab
- **ATC codes:** `L04AC18`

## About

Risankizumab is a monoclonal antibody used to treat psoriasis, psoriatic arthritis, ulcerative colitis, and Crohn's disease. It is an approved interleukin inhibitor and is authorised in the European Union.
