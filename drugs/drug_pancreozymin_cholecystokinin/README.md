# pancreozymin (cholecystokinin)

- **generic name:** pancreozymin (cholecystokinin)

## About

Pancreozymin cholecystokinin is a diagnostic agent used to test pancreatic function. It is administered by intravenous injection from a powder for solution. The drug is listed as withdrawn.
