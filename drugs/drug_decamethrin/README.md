# decamethrin

- **generic name:** decamethrin
- **ATC codes:** `P03BA03`
- **DrugBank:** [DB13600](https://go.drugbank.com/drugs/DB13600) · **PubChem:** none
- **groups:** experimental

## About

Decamethrin is a pyrethroid ester insecticide used to control malaria vectors and in long-lasting insecticidal mosquito nets. Its use is restricted due to widespread resistance in mosquitoes and bed bugs.
