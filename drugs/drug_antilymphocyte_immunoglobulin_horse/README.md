## About

Antilymphocyte immunoglobulin (horse), also called equine anti-thymocyte globulin, is an immunosuppressant used to suppress the immune system, for example in transplant-related settings. It is an approved medicine, though it carries a boxed warning, and its use is typically confined to specialised hospital care.
