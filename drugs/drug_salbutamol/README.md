## About

Salbutamol is a selective beta-2-adrenergic receptor agonist used to treat asthma and obstructive lung disease. It is typically administered by inhalation for rapid relief and is also available for oral use or as an intravenous solution. Salbutamol is a widely used essential medicine available as a generic medication.
