- `invented_absorption`: ka defaulted — not reported in source
- `input_model`: first-order depot input — apparent (/F) parameterization ⇒ extravascular dosing

**Interpretation flags:**
- apparent-ness (ontology-grounded): parameterization=apparent, measured_compound=Psilocybin
- toxin: 1 screen link(s) set aside — no transfer parameter and no metabolite row; one substance's kinetics
- template fit: none — noncompartmental model — not a compartmental parent–metabolite model
- population split: 'psilocin' subgroup of Ley_2023 (paper reports 5 populations: 4-hiaa, nam, psilocin, psilocin glucuronide, tmpaa)
- row roles: 7 per-group rows of Mescaline summary_statistic but 0 reference group(s) — kept as printed
