# cinnarizine

- **ATC codes:** `N07CA02`

## About

Cinnarizine is a calcium channel blocker and antihistamine prescribed for nausea, vomiting, vertigo, and Ménière's disease. It is administered orally in forms such as tablets, capsules, and liquids.
