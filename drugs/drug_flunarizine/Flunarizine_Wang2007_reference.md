### Reviewer guidance

**The flunarizine record was rejected because the elimination rate constant kel is dimensionally inconsistent: it is reported as 0.16 L h(-1), a clearance-like unit, whereas a rate constant should be dimensionless per hour.**

In the Wang_2007 rat record for flunarizine, the parameter labelled Ke is defined as the terminal elimination rate constant, but its value 0.16 carries the unit L h(-1), which describes a clearance rather than a first-order rate constant (1/h). This dimension mismatch on a structural parameter triggered the rejection. The record was also built from the paper's abstract alone, so the reported summary statistics (AUC 6.13 mug.h mL(-1), t1/2 5.32 h) stood in for a fitted model. Extracted — flunarizine: AUC 6.13 mug.h mL(-1), t1/2z 5.32 h, kel 0.16 L h(-1).
