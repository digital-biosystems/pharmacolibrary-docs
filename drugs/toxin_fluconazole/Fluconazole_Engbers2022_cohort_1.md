### Reviewer guidance

**The record was held back because fluconazole bioavailability used a placeholder value instead of an estimate from the paper, and defined covariate effects were not simulated.**

The bioavailability parameter was assigned a generic placeholder value rather than a specific estimate derived from the Engbers_2022 study, rendering the simulated exposure profile unsupported by the source data. Although the record defines covariate effects, only the reference individual was simulated, so these covariate impacts were never evaluated in practice. This leaves the model reliant on unvalidated assumptions for absorption fraction. Extracted — fluconazole: CL 0.0147 L/hour, V 0.844 L, kabs 3.86 h−1, tlag 0.5 h.
