# Iopanoic acid

- **generic name:** Iopanoic acid
- **T3DB:** [T3D4798](http://www.t3db.ca/toxins/T3D4798) · **PubChem:** none

## About

Iopanoic acid is an iodine-containing radiocontrast medium used in cholecystography.

- **Category:** Industrial/Workplace Toxin, Synthetic Toxin
