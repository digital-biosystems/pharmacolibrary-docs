## About

Cefoxitin is a second-generation cephalosporin antibiotic used to treat bacterial infections such as staphylococcal infections, abscesses, sepsis, urinary tract infections, and peritonitis. It is an approved antibiotic used for systemic treatment of bacterial infections, though it carries a boxed warning.
