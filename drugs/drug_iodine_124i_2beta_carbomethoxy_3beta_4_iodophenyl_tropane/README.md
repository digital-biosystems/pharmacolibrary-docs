## About

This iodine-labelled tropane derivative is a radiopharmaceutical imaging agent used to visualise dopamine transporters in the brain, for example in parkinsonian conditions. It is an investigational diagnostic tracer rather than an established marketed medicine, and is not an authorised product in the European Union.
