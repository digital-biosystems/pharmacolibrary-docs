## About

Paramethadione is an oxazolidine-derivative antiepileptic drug used to treat epilepsy, especially absence seizures. It is listed as an approved drug, but it is no longer widely used and is largely unavailable in most countries, partly because of concerns about toxicity during pregnancy.
