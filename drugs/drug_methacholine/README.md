# methacholine

- **generic name:** methacholine
- **ATC codes:** `V04CX03`
- **DrugBank:** [DB06709](https://go.drugbank.com/drugs/DB06709) · **PubChem:** [CID 1993](https://pubchem.ncbi.nlm.nih.gov/compound/1993)

## About

Methacholine is a diagnostic agent used to test airway responsiveness, for example in suspected asthma. It is an approved drug used mainly as a diagnostic agent rather than for treatment.
