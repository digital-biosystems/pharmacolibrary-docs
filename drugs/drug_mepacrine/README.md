# mepacrine

- **generic name:** mepacrine

- **DrugBank:** [DB01103](https://go.drugbank.com/drugs/DB01103) · **PubChem:** none

## About

Mepacrine (quinacrine) is an antiprotozoal drug that has been used against giardiasis and Plasmodium falciparum malaria. It is currently classed as investigational and is not an approved treatment in the European Union.
