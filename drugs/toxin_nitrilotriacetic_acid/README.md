# Nitrilotriacetic Acid

- **generic name:** Nitrilotriacetic Acid
- **T3DB:** [T3D4705](http://www.t3db.ca/toxins/T3D4705) · **DrugBank:** [DB03040](https://go.drugbank.com/drugs/DB03040) · **PubChem:** [CID 8758](https://pubchem.ncbi.nlm.nih.gov/compound/8758)
- **groups:** experimental

## About

A derivative of acetic acid, N(CH2COOH)3. It is a complexing (sequestering) agent that forms stable complexes with Zn2+.

- **Category:** Industrial/Workplace Toxin, Synthetic Toxin
- **Carcinogenicity:** IARC group 2B, possibly carcinogenic to humans.
