### Reviewer guidance

**The clearance value of 1.51 l/hc for lidocaine was rejected because its unit dimension conflicts with the expected volumetric rate.**

The reported unit l/hc possesses a length-squared per time dimension, which is incompatible with the required length-cubed per time dimension for clearance. Since this non-standard unit is absent from the standard conversion library, the system could not compute a valid SI value, causing the parameter to be discarded.
