# Dextroamphetamine

- **generic name:** Dextroamphetamine
- **T3DB:** [T3D3051](http://www.t3db.ca/toxins/T3D3051) · **DrugBank:** [DB01576](https://go.drugbank.com/drugs/DB01576) · **PubChem:** [CID 5826](https://pubchem.ncbi.nlm.nih.gov/compound/5826)
- **groups:** approved, illicit, investigational

## About

Dextroamphetamine is only found in individuals that have used or taken this drug. It is the dextrorotary stereoisomer of the amphetamine molecule, which can take two different forms. It is a slightly polar, weak base and is lipophilic. …

- **Category:** Drug, Synthetic Toxin
- **Route of exposure:** oral bioavailability is over 75%.
- **Sources and uses:** Used to treat attention deficit hyperactivity disorder (ADHD). Used as a psychostimulant drug. [Wikipedia]
- **Mechanism of toxicity:** The exact mechanism of action is not known. Dextroamphetamine stimulates the release of norepinephrine from central adrenergic receptors. …
- **Health effects:** Using large amounts of these drugs can result in a condition known as amphetamine psychosis -- which can result in auditory, visual and tactile hallucinations, intense paranoia, irrational thoughts and beliefs, delusions, and mental confusion.
- **Acute toxicity:** LD50: 96.8 mg/kg (oral, rat).
- **Treatment:** Management of acute amphetamine intoxication is largely symptomatic and includes gastric lavage, administration of activated charcoal, administration of a cathartic, and sedation. …
