# cabozantinib

- **generic name:** cabozantinib

- **groups:** approved, investigational

## About

Cabozantinib is a protein kinase inhibitor used to treat kidney cancer, medullary thyroid cancer, and liver cancer. It is administered orally in tablet or capsule form. The drug is authorised in the European Union for the treatment of these cancers.
