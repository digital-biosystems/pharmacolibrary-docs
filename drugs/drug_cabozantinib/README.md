# cabozantinib

- **generic name:** cabozantinib
- **ATC codes:** `L01EX07`, `L01XE`
- **DrugBank:** [DB08875](https://go.drugbank.com/drugs/DB08875) · **PubChem:** [CID 25102847](https://pubchem.ncbi.nlm.nih.gov/compound/25102847)

- **groups:** approved, investigational

## About

Cabozantinib is a protein kinase inhibitor used to treat cancers such as renal cell carcinoma and medullary thyroid cancer. It is authorised in the European Union for thyroid, kidney, and liver cancers and is used in cancer care.
