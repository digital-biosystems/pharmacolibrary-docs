## About

Amisulpride is an atypical antipsychotic medication used to treat schizophrenia, acute psychotic episodes, depression, and nausea. It is taken orally in tablet form or given as an intravenous injection for postoperative symptoms. This drug is sold in many English-speaking nations but is not available in Canada.
