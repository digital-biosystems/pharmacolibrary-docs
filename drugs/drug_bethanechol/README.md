# bethanechol

- **generic name:** bethanechol

- **groups:** approved

## About

Bethanechol is a parasympathomimetic (muscarinic agonist) used for urinary retention, neurogenic bladder, and gastroesophageal reflux disease. It remains an approved medicine, though it is not authorised in the European Union and is used relatively little today.
