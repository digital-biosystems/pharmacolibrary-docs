# 1,1-Dibromoethane

- **generic name:** 1,1-Dibromoethane
- **T3DB:** [T3D1793](http://www.t3db.ca/toxins/T3D1793) · **PubChem:** [CID 11201](https://pubchem.ncbi.nlm.nih.gov/compound/11201)

## About

1,1-Dibromoethane is an organobromide compound. Bromine is a halogen element with the symbol Br and atomic number 35. Diatomic bromine does not occur naturally, but bromine salts can be found in crustal rock.

- **Category:** Industrial/Workplace Toxin, Synthetic Toxin
- **Route of exposure:** oral, inhalation, dermal
- **Mechanism of toxicity:** Bromine is a powerful oxidizing agent and is able to release oxygen free radicals from the water in mucous membranes. These free radicals are also potent oxidizers and produce tissue damage. …
- **Health effects:** Bromine vapour causes irritation and direct damage to the mucous membranes. Elemental bromine also burns the skin. …
- **Treatment:** EYES: irrigate opened eyes for several minutes under running water. …
