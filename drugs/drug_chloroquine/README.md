# chloroquine

- **generic name:** chloroquine
- **ATC codes:** `P01BA01`, `P01BB52`
- **DrugBank:** [DB00608](https://go.drugbank.com/drugs/DB00608) · **PubChem:** [CID 2719](https://pubchem.ncbi.nlm.nih.gov/compound/2719)

- **groups:** approved, investigational, vet_approved

## About

Chloroquine is an antimalarial drug used to treat malaria, rheumatoid arthritis, and amebiasis. It is administered by mouth or intravenously. It is widely used and listed as an essential medicine.
